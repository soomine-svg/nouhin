システムの特徴

🎙️

歌声やごあいさつの音声も送れます

音声は、園のパソコンからも園のスマホからもお送りいただけます。スマホから送るときは、園のパソコンでフォトポストを開き、画面のQRコードをスマホのカメラで読み取ってください。トリミングは最長1分30秒までお願いいたします。音声の送り方（PDF）

💤

送信中はスリープしません

フォトポストは、送信を始めてから終わるまで、パソコンがスリープしない仕組みです。席を離れるときは、フォトポストの画面をいちばん前に表示したままにしてください。ノートパソコンは、送信中に蓋を閉じないようお願いいたします。お使いのブラウザによっては使えない機能です。その場合は画面の表示に沿ってお使いください。

⏸️

送信を途中でやめても大丈夫

もう一度同じ写真を選び直せば、送信済みは自動でスキップし、未送信の分だけを送信します。

🔁

同じ写真を送っても大丈夫

既に送信済みの写真は自動でスキップされます。「送ったかな？」と迷われる時は、多めに送信されることをお勧めします。

🗂️

園ごと・行事ごと・季節ごとなど自動でフォルダ分け

園様の用途に合わせたフォルダ分けをいたします。

📄

行事予定表などのPDFも送れます

PDFも写真と一緒に送信可能です。複数枚連続するPDFを送信される場合は、ファイル名を「01_表紙」「02_ちゅうりっぷ組」のような付番をお願いします。

📷

カメラの日時設定をご確認ください

カメラの日時設定がされていない写真には、撮影日時情報が残りません。日時情報がないと、アルバム制作やフォルダ分けに大きな支障をきたします。年度初めや、久しぶりに使われる際には日時設定をご確認ください。

スマートフォン・タブレットは自動で合いますので、確認は不要です。

🔒

URLとパスワードの取り扱い

URLはブックマークをお勧めします。パスワードは園の外には出さないようにお願いいたします。

Q仕分けた写真は、園のパソコンにどう戻るの？
写真そのものは送り返しません。「どの写真がどのお子さまか」の一覧表だけをお返しし、園のパソコンの中にある写真と突き合わせて、お子さまごとのフォルダを作ります。写真を送り合わないので、誤送信の心配がなく、受け取りも一瞬です。
Qどうして名前を変えても見つかるの？
写真には、名前とは別に、中身から決まる「指紋」のようなものがあります。一覧表はその指紋で写真を探すので、名前が変わっても同じ写真だと分かります。切り抜きや回転をすると指紋が変わり、別の写真になってしまいます。

まとめ：① 送った写真はそのまま　② 使うときはコピーを別名で　③ 整理は振り分けが終わってから

6写真の保存場所とフォルダの作り方6問

共有フォルダで写真を管理している園向け。保存してから、フォトポストへ

Q1写真は、どこに保存すればいい？
クラスのスマホから、園の共有フォルダへ直接保存してください。ICT や LINE WORKS を通した写真は、画質が下がり撮影日時も消えるため、見本写真やアルバムに使えません。
操作スマホ本体の写真を → ケーブルでパソコンに取り込む → 共有フォルダへ保存
→ 図解を見る画像を押すと大きく開きます
Q2共有フォルダの中は、どう分ける？
共有フォルダ ＞ クラスのフォルダ の2段で大丈夫です。クラスのフォルダの中は、「見本写真」と「写真」（日常・行事）の2つに分けてください。業者さん撮影分は、別のフォルダのままで結構です。
→ 図解を見る画像を押すと大きく開きます
Q3行事で分けるほうがいい？
どちらでも大丈夫です。行事予定表を提出済みの場合は写真に含まれる撮影日時データで見分けます。行事予定表を未提出、撮影機器の日時合わせをしていない場合は 行事名_日付（例：運動会_20261010）にしていただけると確認が早くなります。
→ 図解を見る画像を押すと大きく開きます
Q4どのフォルダを選んで送る？
断然、全ての画像をまとめている親フォルダ一択です。すでに送信済みのものは自動でスキップされますのでフォルダを選ぶ必要もありません。ただし、過去の年度のものはチェックを外してくださいね。
→ 図解を見る画像を押すと大きく開きます
Q5送ったあと、共有フォルダの写真はどうする？
そのまま残してください。お届けする「振り分け表」は、共有フォルダにある写真と突き合わせて、お子さまごとのフォルダを作ります。写真が無いと、そのお子さまのフォルダに入れられません。
→ 図解を見る画像を押すと大きく開きます
Q6スマホから直接フォトポストに送ってもいい？
日常の写真は、共有フォルダに保存してからお送りください。スマホから直接送ると、その写真が共有フォルダに保存されていないため、振り分けの結果が反映されなくなります。音声は、スマホから直接お送りいただけます（7章）。
→ 図解を見る画像を押すと大きく開きます

まとめ：① スマホから共有フォルダへ　② クラスの中は見本写真と写真　③ 親フォルダを選んでクラスにチェック

7音声の送り方7問

歌声やごあいさつの録音を、園のパソコンからも園のスマホからも

Q1音声も送れるの？
はい。歌声やごあいさつの録音を、フォトポストからお送りいただけます。音声は自動で、写真とは別に整理されます。
→ 図解を見る画像を押すと大きく開きます
Q2スマホからも送れる？
はい。園のパソコンでフォトポストを開き、画面のQRコードをスマホのカメラで読み取ると、スマホにフォトポストが開きます。パスワードは、これまでと変わりません。
操作パソコンでフォトポストを開く → QRコードを読み取る → パスワードを入れる
→ 図解を見る画像を押すと大きく開きます
Q3どのくらいの長さがいい？
アルバムに載せる音声は、1本につき最長1分です。お送りいただく録音は、最長1分30秒までにトリミングをお願いいたします。載せる部分は、こちらで選ばせていただきます。
→ 図解を見る画像を押すと大きく開きます
Q4スマホでは、どこに保存する？
クラウド（iCloud Drive・Google ドライブ）か、端末内（このiPhone内・内部ストレージ）です。迷ったら、端末内をおすすめします。クラウドはご契約の容量を使います。
→ 図解を見る画像を押すと大きく開きます
Q5Android にもボイスメモはある？
機種共通のボイスメモはありません。Galaxy は「ボイスレコーダー」、Pixel は「レコーダー」です。そのほかの機種は、アプリの一覧で「録音」を探してください。
→ 図解を見る画像を押すと大きく開きます
Q6ボイスレコーダーの録音は？
機器の説明書に沿って録音を園のパソコンへ移し、写真と同様にフォルダを選んでお送りください。形式は m4a・mp3・wav・aac です。これ以外の形式のときは、お尋ねください。
操作パソコンへ移す → フォルダを選ぶ → チェックして送る
→ 図解を見る画像を押すと大きく開きます
Q7雑音が入ってしまった
そのままお送りください。雑音の軽減と音量の調整は、こちらでいたします。先生の作業はございません。
→ 図解を見る画像を押すと大きく開きます

まとめ：① 最長1分30秒にトリミング　② スマホに保存またはパソコンへ　③ フォトポストで送る
